# Test audio

`consultation_yue_16k.wav` — 90 s, 16 kHz mono PCM16.

Synthetic Cantonese clinical dialogue, generated with text-to-speech from a
scripted consultation. Not a recording of a real person and not patient data.

Cantonese is deliberate: it stresses code-switching and CJK segment merging in
ways an English sample would not. Any 16 kHz mono PCM16 file works via `--audio`.
